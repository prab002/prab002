### 🧑‍💻 About Me

I'm a developer who likes to **build across the whole stack — and beyond it.** I started with full-stack web and kept expanding into the things that interested me: native desktop apps, AI, and markets.

- 🌐 **Full-stack web** with the **MERN** stack and **Next.js** — fast, responsive frontends backed by clean, scalable APIs and databases.
- 🦀 **Rust + Tauri** — I build and ship native, high-performance **desktop apps** (including a macOS app I shipped end to end).
- 🤖 **AI & LLMs** — integrating language models into real products: assistants, automation, and intelligent features.
- 📈 **Algorithmic / Quant Trading** — designing and experimenting with data-driven trading strategies and automation.
- ⚙️ **Ship it, don't just build it** — **CI/CD with GitHub Actions**, automated releases, code signing, and proper repo hygiene are part of how I work.
- 🧩 I love **solving hard problems** and turning ideas into polished, real products.

> 💬 Always up for collaborating on ambitious projects — web, desktop, AI, or trading. Let's build something amazing.
